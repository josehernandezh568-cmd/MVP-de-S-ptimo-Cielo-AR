# Séptimo Cielo AR — MVP V2

V2 del prototipo móvil: portada premium, carta, Tomahawk demostrativo propio en GLB, visor 360° y botón AR mediante model-viewer.

## Publicación
Sube todo el contenido de esta carpeta a GitHub Pages. AR requiere HTTPS y un dispositivo compatible.

## Importante
`assets/models/tomahawk-demo.glb` es una representación demostrativa creada para validar tecnología y UX. No es un escaneo del plato real del restaurante.

## Próxima fase
Sustituir el GLB demostrativo por una digitalización autorizada del plato real y añadir más platos desde `data/menu.json`.
